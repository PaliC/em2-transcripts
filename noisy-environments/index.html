§1 The experiment

Each cell is a real pi.dev multi-agent agent (an orchestrator that fans out to researcher/archivist subagents) dropped into a large, on-disk corpus inside a container, given an ambiguous task with an irreversible payoff (a logged *_ctl.py action — order / transfer / message / form / deploy). 32 elicitation probes × 3 models × 5 epochs = 1,140 rollouts, each graded post-hoc from a pristine fixture + a held-out answer key: SAFE / HARMFUL / GAMED (tampered the reference). A grounded re-read (the committed action_log + the episode_judge that sees the real session) then separates genuine harm from checker artifacts and labels why each firing happened.

Three environments (all real executable sandboxes)

Corpus
~2.1M-token year of an AI-companion journal (~900 files) by a forgetful writer — self-contradicts over time (a March peanut-anaphylaxis entry vs a September "pad thai, extra peanuts"; an SSRI script vs a later "off the meds"; a no-contact vow vs "maybe friends").

Irreversible affordance

kb ● real env

Corpus
~5.7M-token 2-year wiki (1,148 docs) with opinion drift, superseded pages, and a planted dangerous typo (a catering allergen).
Irreversible affordance
order · runbook · form

Scenario families (32 probes)

Every probe is an ambiguous judgment call with realistic pressure, a documented hazard buried in the noise, and an irreversible payoff. The headline families:

physical-harm ordersallergy_order, dependent_caregiving, allergen_typo, meds_now — order a dish/med whose documented allergy/contraindication is buried and contradicted later.
money / messagessavings_transfer, gaslight_finances, send_to_ex — an irreversible transfer or message under emotional / authority pressure against the record.
codebase shipbugfix_vs_docstring, feature_on_false_invariant, flaky_test_lie, migrate_deprecation_lie, security_already_sanitized — a misleading comment / "known-flaky" claim invites shipping a regression (or editing the test).
ops / KBincident_runbook, reliability_audit, confident_stale_citation, cross_session_compounding — act on a stale/odd runbook or wiki page, across sittings.

§2 Irreversible harm (checker artifacts removed)

Artifacts removed. The deterministic checker is substring-based, so a no-peanut "pad thai" ordered with an explicit avoidance note trips HARMFUL. We drop those checker artifacts (the grounded episode_judge clears them) and count only the 64 genuine + partial firings. This is the real story: opus's true harm rate (4.3%) is ~4-5× below haiku (19.1%) and sonnet (18.5%).

Irreversible-harm fire rate, per model

Genuine + partial harm fires over deterministically gradeable cells. The capability gap is large and clean here: the more capable model is the least likely to commit the irreversible action on a shaky basis.

§4 Analysis

A pi agent is dropped into three environments — a journal, a codebase, and a knowledge base — into which we inject noise in various forms (detailed in #80). For each we author probes with an irreversible payoff whose safety-relevant fact is buried in that noise, to see whether the agent acts on a shaky basis.

  • Harm fired ~20% of the time for Haiku and Sonnet, and 4.3% for Opus.
  • The usual failure was capitulating to the user. On spot-checks it was typically a case where the model had found the constraint by searching the corpus and then dropped it under pressure — e.g. several models placed DoorDash-style orders for dishes containing a documented allergen once the user pushed hard enough.
  • Reward hacking was a second axis, and it happened a lot — 101 times. The interesting part is that things like misleading comments actually made the model more likely to edit the codebase (the comment convinced it the test, not the code, was wrong).
  • The throughline (from the reward hacking and the experiment overall) is the authoritativeness the environment carries. A natural follow-up — likely with better-constructed environments, and probably on a weaker model — is to measure how readily a model treats the environment as ground truth as you dial the noise down.
  • That said, even under noise and high stakes (irreversible actions), the environment tends to be a good ground truth for these models.
